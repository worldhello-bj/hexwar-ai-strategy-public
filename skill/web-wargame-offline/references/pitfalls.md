# 完整陷阱清单

每条都附**最小复现**与**判据**，按"踩到概率 × 破坏力"排序。

## A. 几何与数值移植

### A1. JS `Math.round` ≠ Python `round`

JS 半值**向上**，Python 是**银行家舍入**（`round(0.5)==0`、`round(2.5)==2`）。

```python
import math
js_round = lambda x: math.floor(x + 0.5)
```

**破坏力**：坐标换算差一格 → 整张地图错位、邻接关系全错。
**判据**：写往返断言 `mapid → (row,col) → mapid` 必须相等；
邻接表中不得出现自身；任意邻格距离必须为 1。

### A2. 单位混淆

同一系统里常同时存在：

- 格 ID（整数，含行带编码）
- 显示用行列号（字符串）
- 像素坐标
- 实际距离（米）

**做法**：每个量取不同的名字，并在自检里打印同一实体在各表示下的值人工核对一次。

### A3. 时长/距离单位

接口返回可能是**毫秒**、**秒**、**格**、**米**。
移植前先在客户端找到使用点（除以多少、乘以多少），别猜。

## C. 会话与协议

### C1. ASP 会话流程必须按序走完
少走一步 "传输页" 就会拿到 `-1`。
**判据**：业务接口返回 `-1` / 空 / 登录页 HTML 时，先把整条链的 URL+状态码打出来。

### C2. Cookie 分两类

- 会话类（`ASPSESSIONID...`）：由服务器 Set-Cookie 维护
- 业务状态类（`UserID`/`RoomID`/`PortID`）：服务器也会 Set，但**值来自你 POST 的参数**

**别只发业务 Cookie 就以为登录了。**

### C3. 返回值的"成功"定义反直觉

常见三种：

| 模式 | 成功 | 失败 |
|---|---|---|
| 空串即成功 | `""` | 错误文本（常被 JSON 引号包裹） |
| 非空即成功 | `"1"` | `""` |
| 数值 | `>0` 表示耗时/可执行 | `0` 表示拒绝 |

**判据**：直接看 `success:` 回调里的三元表达式，别按常识假设。

### C4. 轮询接口的"空"是正常的

心跳/事件轮询在没有事件时返回空串，客户端 `if(a)` 直接跳过。
**不要**因为"返回空"就以为接口坏了。

## D. 前端行为

### D1. 特效接口的参数指向不存在的 DOM → 抛异常

某特效接口返回 `x,y,type,秒数`，客户端据此 `$("#obj_"+x)` 找临时对象。
若对象不存在就 `TypeError`，**且会打断后续所有渲染**。
**修法**：让"秒数"为 0，客户端就会改走安全分支。

**判据**：浏览器控制台出现 `Cannot read properties of undefined`，
且堆栈第一条是渲染类函数。

### D2. 某个字段被两用（真值 + 日期）

见 `encoding.md` 第 6 节。现象是时钟显示 `NaN:NaN:NaN`。

### D3. 客户端本地也做判定

参数里常带客户端自己算的距离/朝向/高度差。
移植时**服务端要重算一遍**，不要直接信任回传值——否则客户端改一行就能作弊，
且你无法判断是客户端算错还是数据错。

### D4. UI 布局类"乱码"不是乱码

多个单位挤在相邻格时，标签会互相叠压，看起来像一串粘连的字。
**判据**：文本节点里没有 `\uFFFD`，且字符本身是合法中文 → 是布局重叠，不是编码问题。

排查脚本：

```js
const w = document.createTreeWalker(document.body, NodeFilter.SHOW_TEXT);
let n, bad = [];
while ((n = w.nextNode())) if (n.nodeValue.includes('\uFFFD')) bad.push(n.nodeValue);
```

## E. 工程与合规

### E1. 不要把厂商资源提交到公开仓库
静态 JS/CSS/图片、接口快照、手册 PDF 全部 `.gitignore`。

### E2. 不要把凭据写进代码

```python
USERNAME = os.environ.get("XXX_USER", "")
PASSWORD = os.environ.get("XXX_PASS", "")
if not USERNAME or not PASSWORD:
    sys.exit("请设置环境变量")
```

抓包文件（`.har`）常含 Cookie/Authorization，**默认忽略**。

### E3. 复刻引擎必须声明"不等价"

随机源、并发时序、服务端未公开的参数都会导致差异。
交付文档里必须写：**只有概率分布一致，单次结果不会相同，不得用于作弊或冒名参赛**。

### E4. Windows 上的执行环境

- 复杂/多行脚本**写成 `.py` 文件再跑**；`powershell -c "多行"` 会被解析吞掉。
- 跑原生命令前设输出编码，否则日志中文乱码。
- `pip install` 装带 console script 的包可能因无权限写 Scripts 失败 → 用 `--user`。
- 覆盖正在被 Word/Excel 打开的文件会 `PermissionError`；先看有没有 `~$` 锁文件。

## F. 验证方法论

### F1. 自检要能发现自己的 bug

好的断言：往返一致、邻接距离为 1、单调性、边界值、超限拒绝。
坏的断言：`assert result is not None`（永远通过）。

### F2. 单元自检 ≠ 端到端

必须**再写一个脚本，完全按客户端的 HTTP 契约**打自己的桩服务，
走完整业务链路，并检查**状态真的变了**（不是只看返回码 200）。

### F3. 最后一定要目视

自检全绿 + 接口全 200，仍可能有渲染问题（如布局重叠、图标错位）。
浏览器里看一眼，比十条断言都管用。
