# Hexwar 兵棋推演平台 —— 客户端/服务端接口对照表

> 证据来源：`www.hexwar.cn.har`（2026-10-14 实抓 271 条请求）+ `war.min.js`（163,402 字节）+ 一次登录态实抓。
> 标注：**已验证** = HAR 中有真实请求/响应；**代码证据** = 只能在 `war.min.js` 中看到调用点；**推断** = 未直接观测。

## 0. 系统形态

| 项 | 值 |
|---|---|
| 服务端 | Microsoft IIS 7.5 + Classic ASP（会话 Cookie `ASPSESSIONIDXXXX`） |
| 练习入口 | `http://www.hexwar.cn/WARGAMEAI/`（登录 → 推演大厅） |
| 客户端入口 | `http://www.hexwar.cn/WARGAMEAI7/main.html` |
| 客户端技术 | jQuery 1.8.3 + 自研 `war.min.js`（163 KB 压缩）+ iScroll-zoom + jAlert |
| 静态 CDN | `http://cdn1.hexwar.cn/`（单位图标 `ico/`、`icon/`、地图底图 `maps/`） |
| 编码 | 页面 `main.html` 声明 `gbk`；**所有 `.asp` 输出为 GBK 字节** |
| 会话 Cookie | `ASPSESSIONID…`（每次会话都不同，**此处不记录具体值**）、`UserID`、`UserRoom`、`PortID`、`UserRole`、`UserAdmin` |

架构：**浏览器只做渲染与输入，状态与裁决全在 ASP 后端**。客户端不再维护权威状态，所有
单位态势通过 `ObjAjax.asp` 每秒轮询获得。

### 地图格字段（`Map_Get.asp`）

| 字段 | 含义 |
|---|---|
| `mapid` | 格 ID。`10000×行带 + 列偏移`，奇偶决定是否半格错位 |
| `hexid` | 显示用行列号 `RRCC`（`HexID(mapid)`：行=2×行带+奇偶，列=round(偏移/2)） |
| `note` | 地物注记（如"火车站"） |
| `cond` | 附加状况：0 无、6 桥、7 水、8/9 特殊（见 `war.min.css` 的 `.condN`） |
| `step` | 通行步耗（0 不可通行） |
| `hex` | 地形贴图号 → `Hex1/<hex>.png` |
| `hextype` | 0 普通、1/10 放大贴图（68×68，偏移 -5,-5）、2 简单贴图 |
| `elevation` | 高程（米） |

## 5. 已确认的缺口
