# 离线客户端使用说明

## 一、这是什么

把官方前端（`WARGAMEAI7`）完整镜像到本地，并用**本地桩服务**顶替全部 `.asp` 接口，
数据来自 2026-10-14 21:41 抓取的真实对局快照（推演室7 / 想定 7527「城市攻防作战 2V2」）。

**完全离线**：不会向 `www.hexwar.cn` 或 `cdn1.hexwar.cn` 发出任何请求，已在断网等价条件下验证
（服务器访问日志显示所有请求都打到 `127.0.0.1:8080`）。

## 二、怎么跑

```powershell
py -3.13 d:\兵推\offline\server.py
```

然后浏览器打开 <http://127.0.0.1:8080/>

端口可用环境变量改：`$env:HEXWAR_PORT=9000; py -3.13 d:\兵推\offline\server.py`

停止：在终端按 `Ctrl+C`。

## 三、现在能做什么

- 看到**真实想定地图**：100×18 六角格、高程配色、地形贴图、水系、道路、火车站等注记。
- 看到**真实初始态势**：36 个算子（红 6 / 蓝 15 / 未上阵 15），含 3 个城市目标。
- 官方界面的全部图层按钮可用：兵棋图/卫星图/地形图/背景图、六角格/方里格/无网格、
  模型/图标/算子、地形、高程、测量、战损、成绩。
- 单位可点选，属性面板可弹出（依赖 `com/CommandObj.asp` 等接口的桩数据）。

## 四、现在**不能**做什么（重要）

推演无法真正开始与推进。原因：

| 缺失项 | 对应接口 | 现状 |
|---|---|---|
| 服务端裁决引擎 | `com/Attack.asp`、`jmCaijue.asp`、`CityTake.asp` | 未下发，仅知调用契约 |
| 回合推进与时钟 | `RoomStart.asp`、`RoomStat.asp`、`ComAjax.asp` | 返回空 → 保持"未开始" |
| 裁决结果回填 | `ObjAjax.asp`（动态状态） | 返回的是**抓取当时的静态快照** |
| 装备/规则参数表 | `data=387` 等 `data` 字段的内容 | 只在服务端数据库 |

也就是说：**这是"态势复现器"，还不是"可对抗的离线裁判"**。

## 六、编码规则（踩过的坑）

本站**不是全站统一编码**：

| 资源 | 编码 |
|---|---|
| `main.html` | GBK |
| `war.min.js` | GBK（含中文注释与提示语） |
| `war.min.css` / `user.css` / `observe.css` / `common.css` | GBK |
| `lib/jAlert/js/jquery.alerts.js` | GBK（”确认/取消“按钮文案） |
| `lib/paint/paint.js` | GBK（”不通视/能观察/距离“） |
| `lib/jquery-1.8.3.min.js` | 纯 ASCII |

**服务器必须按每个文件的真实编码声明 charset**（`server.py` 的 `detect_charset()`）：
UTF-8 能解开就 utf-8，解不开就 gbk，纯 ASCII 不声明。
如果无脑声明 `charset=utf-8`，GBK 文件里的中文会变成 `ȷ��` 这类乱码。

同理，`.asp` 输出也必须是 GBK 字节 + `charset=gbk`。

## 七、会话字段的类型要求

客户端算「推演时间」用的是 `GameTime() = SecDiff(ServerTime,StartTime) - SecDiff(Time1,WarDateTime)`，
所以 **`Time1` / `StartTime` / `WarDateTime` 必须是日期串**（如 `2026/10/14 22:02:57`），
不是数字。`Time1` 只用于真值判断（`Time1?`、`!Time1`），填日期串不会影响逻辑。
否则时间会显示成 `NaN:NaN:NaN`。

另外 `GetServerTime.asp` 必需实现，否则它会把 `ServerTime` 覆写成空串。
